## 3. Mandatory Guardrail Policies

All guardrails remain strictly active and mandatory:
- **ROOKIE_NO_HISTORY anchor**: True rookies/prospects with 0 NFL career games are locked to Current Pigskin.
- **LOW_HISTORY anchor**: Players with > 0 but < 10 historical NFL career games are locked to Current Pigskin.
- **PROSPECT_HISTORY manual review**: Single-season prospects (Cam Ward, Tetairoa McMillan, Omarion Hampton) are flagged for manual review if inside top 150 overall equivalent.
- **Sparse-feature cap**: Players missing > 50% features capped at max +10 upward movement.
- **Model-disagreement lock**: divergence > 20 ranks anchors to Current Pigskin (disabled for QBs).
- **QB rushing-bias warning**: Flags QBs elevated primarily on rushing stats.
- **Standard TE floor**: Restricts standard TE demotion below Current Pigskin.
- **Held-board lock**: Low-correlation boards remain strictly locked to Current Pigskin queues.
- **Route metrics status**: True route run metrics remain strictly **BLOCKED** and mapped to `NULL`.

## 5. Position-Locked Top-100 Interleaver Planning

The owner has authorized planning for a future **position-locked top-100 interleaver**. The technical implementation of this planner must follow these rules:

1. **Positional Queue Integrity**: The top-100 planner must pull exclusively from the position-locked queues (e.g., QB, RB, WR, TE) generated by the guarded BQML v2 positional boards.
2. **No Reordering**: The planner must not reorder players within individual positional boards. The order of players inside each positional board (e.g., standard WR1 through WR100) is strictly locked.
3. **Queue Selection Logic**: The planner may decide which positional queue to pull from next based on value-over-replacement (VOR) or alternate ranking logics, but the chosen player must be the next available player from that position's queue.
4. **Guardrail Compliance**: All active positional guardrails remain in effect.
5. **Held Boards Preservation**: Positional boards marked as *Held behind Current Pigskin* (e.g., PPR TE) must use the Current Pigskin positional queue as their input.
6. **No Route Metrics**: Route run metrics remain strictly **BLOCKED** and mapped to `NULL`.
7. **No Live Activation**: This planning document does not activate any draft rankings or champion labels on the live server.
